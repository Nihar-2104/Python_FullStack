Q1)Name 5 IT job roles and write one line about what each role does.
Ans: Software Developer – Develops, codes, tests, and maintains software applications and websites.
Software Tester (QA Engineer) – Tests software to find bugs and ensures the application works correctly and meets requirements.
UI/UX Designer – Designs the look, feel, and user experience of websites and applications.
Data Analyst – Analyzes data to identify trends and provides insights that help businesses make better decisions.
AI Engineer – Builds and integrates artificial intelligence and machine learning systems to solve real-world problems.

Q3)Write the full forms and one-line use of: GitHub, Slack, Jira, IDE, API.
Ans: 1. GitHub
Full Form: GitHub does not have a specific full form (it is named after "Git," which is a version control system).
Use: It is a platform where developers can store their code online, track changes, and collaborate on projects together.

2. Slack
Full Form: Searchable Log of All Conversation and Knowledge.
Use: It is a messaging app used by professional teams to communicate, share files, and organize their work conversations.

3. Jira
Full Form: Jira does not have a full form (the name is actually derived from "Gojira," the Japanese word for Godzilla).
Use: It is a project management tool used by software teams to plan tasks, assign work, and track bugs or issues.

4. IDE
Full Form: Integrated Development Environment.
Use: It is a software application that provides programmers with all the tools they need to write, edit, and test code in one single place.

5. API
Full Form: Application Programming Interface.
Use: It acts as a bridge or messenger that allows two different software programs to talk to each other and share data.

Q4)Name any 5 programming languages and mention one popular use case for each.
Ans: 1. Python
Use Case: It is widely used for Artificial Intelligence (AI) and data analysis because it is very easy to read and has powerful libraries.

2. JavaScript
Use Case: It is mainly used in web development to make websites interactive and build dynamic user interfaces that run in the browser.

3. Java
Use Case: It is very popular for building Android mobile applications and large-scale software systems for companies.

4. C++
Use Case: Because it is very fast and powerful, it is heavily used for developing high-end video games and system software.

5. SQL(Structured Query Language) 
Use Case: It is specifically used for managing, storing, and retrieving data inside relational databases.



Q5)What is the difference between a developer and a tester? Answer in 2 lines.
Ans: A Developer creates and maintains software by writing code, adding features, and fixing coding-related problems.
A Tester checks the software to find bugs, verify that features work correctly, and make sure the software meets the required expectations.
