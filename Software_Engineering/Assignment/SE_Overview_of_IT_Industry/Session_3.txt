Q1) Write the full form and one-line use of: HTTP, HTTPS, FTP, SMTP.

Ans:

1. HTTP – HyperText Transfer Protocol
   Use: It is used to transfer web pages and other data between a web browser and a web server.

2. HTTPS – HyperText Transfer Protocol Secure
   Use: It is the secure version of HTTP that encrypts data transferred between the browser and the web server.

3. FTP – File Transfer Protocol
   Use: It is used to transfer files between a client computer and a server over a network.

4. SMTP – Simple Mail Transfer Protocol
   Use: It is used to send emails from an email client to a mail server and between mail servers.

Q2) What is the difference between IPv4 and IPv6? Answer in 2 lines.

Ans:

IPv4 uses 32-bit addresses, such as 192.168.1.1, and provides about 4.3 billion possible addresses.

IPv6 uses 128-bit addresses, such as 2001:db8::1, and provides a much larger number of IP addresses.

Q4) What do these HTTP status codes mean: 200, 301, 404, 500, 403?

Ans:

1. 200 – OK: The request was successful and the server returned the requested information.

2. 301 – Moved Permanently: The requested resource has been permanently moved to a new URL.

3. 404 – Not Found: The requested page or resource could not be found on the server.

4. 500 – Internal Server Error: The server encountered an unexpected problem while processing the request.

5. 403 – Forbidden: The server understood the request but refuses to allow access to the requested resource.

Q5) Explain DNS hierarchy (root, TLD, domain, subdomain) with [www.google.com](http://www.google.com) as an example.

Ans:

DNS – Domain Name System – is a system that converts human-readable domain names into IP addresses.

1. Root (.) – The root is the top level of the DNS hierarchy and directs requests to the appropriate TLD servers.

2. TLD (.com) – TLD means Top-Level Domain. In [www.google.com](http://www.google.com), “.com” is the TLD.

3. Domain (google) – “google” is the main domain name registered under the .com TLD.

4. Subdomain (www) – “www” is a subdomain or host name used to identify a particular service or server under the google.com domain.

Therefore, in [www.google.com](http://www.google.com):

www → Subdomain/Host
google → Domain
.com → TLD
. → Root
